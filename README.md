# TrackProgress

TrackProgress is a frontend design concept for an app that helps people set goals, build consistent habits, and see their progress over time.

> **Project status:** Frontend concept / UI prototype. The complete TrackProgress product has not been built yet.

## Preview

[View the live frontend preview](https://trackprogress-ten.vercel.app/)

## About the project

This repository explores the visual direction and user experience for TrackProgress. It focuses on creating a calm, motivating interface for turning personal goals into visible progress.

The current version is a design-led frontend exploration. It does not yet include a production backend, authentication, persistent user data, or a complete tracking system.

## Planned product direction

- Create and organize personal goals
- Break goals into manageable tasks or milestones
- Track daily and long-term progress
- View progress through clear dashboards and visual summaries
- Encourage consistency with milestones and motivating feedback

## Tech stack

- Next.js
- TypeScript
- Tailwind CSS
- React

## Getting started

Clone the repository and install the dependencies:

```bash
git clone https://github.com/thobee/Trackprogress.git
cd Trackprogress
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
